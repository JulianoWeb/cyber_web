# Web Tools Flask 🌐

Projeto simples feito em Python e Flask com algumas ferramentas web.

## Funcionalidades

* Verifica o status de um site
* Consulta CEP
* Encontra links de uma página
* Interface web com HTML

## Instalação

```bash
pip install flask requests beautifulsoup4
```

## Como usar

```bash
python app.py
```

Depois acesse:

```text
http://127.0.0.1:5000
```

## Tecnologias

* Python
* Flask
* Requests
* BeautifulSoup
* HTML
